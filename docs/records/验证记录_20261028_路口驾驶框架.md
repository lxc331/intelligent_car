## 1. 绿灯确认起步（默认关）

`app/carapp/core/traffic_scene.py`

- 新增参数：`green_area_min`（默认 300 px²）、`release_green_frames`（默认 **0**）、`release_timeout`（默认 12 s）。
- 新增状态：`green_area/green_visible/green_streak/green_pending/waiting_green/red_cleared_at`。
- 放行规则：
  - `release_green_frames == 0`（默认）：红灯消失即可走，和原来一致；
  - `> 0`：红灯从画面消失后先把 `red_pending` 按住，等连续 `release_green_frames` 帧绿灯
    （面积 > `green_area_min`）才真正解除；等灯期间 `snapshot()["waiting_green"]` 为真、
    `scene` 文案为「红灯已消失，等待绿灯确认」；
  - 兜底：等待超过 `release_timeout` 秒自动放行（灯具坏了 / 视角偏了不会永久钉住）。
- 绿灯框与红灯同为「正前方」过滤（横向 15%–85%、纵向 2%–95%，后者为仰视时灯贴画面下沿留的余量）。
- 配置：`traffic_light.green_area` / `release_green_frames` / `release_timeout`，由
  `features/traffic_light._build` 传入。
- **为什么默认关**：实车仰视 1380 / 1720 时右侧竖直绿灯整帧与放大块检出都是 0 分，打开会一直停着；
  明天采到仰视绿灯样本、确认稳定召回后再设 2–3。

## 2. 路口停车/起步框架（驾驶层，尚未接车轮）

新增 `app/carapp/core/junction_drive.py`（纯逻辑，210 行）：

- `parameters(cfg)`：从 `settings.json` 的 `junction` 段读取并校验 8 个参数，
  要求 `0 < brake_distance < stop_distance < slow_distance`，报错文案「路口参数无效 / 缺少路口参数 /
  路口距离门限必须满足 刹停 < 停止线 < 减速」。
- `StopLineDrive.step(scene, distance, now)`：输入交通场景快照（只读 `red_pending` / `red_required` /
  `crosswalk_active`）与**离停止线距离**（米，允许 `None`），返回 `DriveCommand(speed, phase, note)`：

| 阶段 | 条件 | speed |
|---|---|---|
| `idle` | 无红灯、未确认路口 | `None`（不限速） |
| `hold` | 红灯但 `distance is None` | `0.` |
| `approach` | 红灯，距离 > `slow_distance` | `approach_speed` |
| `slow` | 红灯，`stop_distance` < 距离 ≤ `slow_distance` | `slow_speed` |
| `crawl` | 红灯，`brake_distance` < 距离 ≤ `stop_distance` | `crawl_speed`，超 `crawl_timeout` 转 `hold` |
| `hold` | 红灯且距离 ≤ `brake_distance` | `0.` |
| `go` | 路口确认且无红灯 | 贴停止线 `go_speed`，否则 `approach_speed` |

- **不发布 Twist、不碰舵机**：速度上限交给现有 `guard_twist` / `limit_twist` 那条路径使用，
  方向盘、倒车、避障都不在这里，符合 AGENTS.md「core 放算法、保持可脱离 Tk 测试」。
- 配置 `junction`：`slow_distance 3.0`、`stop_distance .9`、`brake_distance .35`、
  `approach_speed .12`、`slow_speed .08`、`crawl_speed .04`、`go_speed .10`、`crawl_timeout 8.0`，
  全部是占位值，注释写明「明天实测停车距离和实际速度后改」。

## 3. 离线演练（不连车）

`.work/offline_junction_drive.py`：用已录实车帧 + 假想测距跑完整链路（读 `load_config()`，所以用的是
当前 2 号车的三视角 1450/1600/1380）。实测输出：

```
view   red  active  blocked  phase   speed  note
car2_1500.jpg   False False False  idle      --
car2_1500.jpg   True  False False  approach  0.12  前方红灯，俯视确认斑马线 1600
                -> 云台 pitch 1600
pitch_1600.jpg  True  False False  slow      0.08  红灯，减速
pitch_1600.jpg  True  True  True   slow      0.08  斑马线确认，抬头确认红灯 1380
                -> 云台 pitch 1380
stop_lookup_1720.jpg True True True crawl    0.04  红灯确认，斑马线前停车
stop_lookup_1720.jpg True True True hold     0.00  到达停止线，停车
```

顺序与设计一致：**前视看到红灯 → 俯视确认停止线 → 仰视确认红灯 → 减速爬到停止线 → 停车**。
