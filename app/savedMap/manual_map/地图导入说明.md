# 手绘沙盘地图导入说明

在 App 的“沙盘导航 + 实时展示”页点击“导入地图（YAML）”，选择本文件夹下的 **rawMap.yaml**。它引用同目录 **rawMap.pgm**，移动或复制地图时请将这两个文件一起保留。

## 文件与尺度

- `rawMap.png`：你们提供的纯黑白原图，保持原样。
- `elaborateMap.png`：你们提供的尺寸标注图，保持原样，仅用于核对尺寸。
- `rawMap.pgm`：由纯黑白原图逐像素无损导出的 ROS 地图图像。
- `rawMap.yaml`：ROS/Nav2 地图描述，使用相对路径引用配套 PGM。

原图为 **594 × 1080 像素**，对应 **宽 2.97 米 × 长 5.40 米**。两个方向的比例都为 **0.005 米/像素，即每像素 5 毫米**。

像素核对结果：横向 50 + 89 + 52 + 81 + 25 = 297 厘米；纵向 52 + 150 + 51 + 235 + 52 = 540 厘米。四块黑色障碍物分别为 89×150、81×150、89×235、81×235 厘米，与标注图一致。原图四周的 1 像素黑框也予以保留，对应 5 毫米的占用边界。

黑色表示占用、白色表示空闲；本图没有未知区域。文字、箭头和蓝色道路参考线不参与导航地图。

## 坐标约定

地图原点设在图片左下角的外边缘，`origin: [0.0, 0.0, 0.0]`。这是为手绘地图定义的坐标，不是自动推断的小车当前位置。

- x 向图片右侧增加，范围 0–2.97 米。
- y 向图片上方增加，范围 0–5.40 米。
- 朝向 0 表示朝图片右侧；朝图片上方为 +90°，朝左为 ±180°，朝下为 -90°。

道路参考中心位置：左路 x≈0.25 米，中路 x≈1.65 米，右路 x≈2.845 米；下方横路 y≈0.27 米，中间横路 y≈3.125 米，上方横路 y≈5.13 米。这些坐标仅作找点参考，不代表方向限制或自动生成的导航目标。

## 导航操作与适用范围

1. 先结束建图或其他导航服务，再导入 `rawMap.yaml`。
2. 连接并启动导航定位。
3. 选择“标定当前位置 / 朝向”，在地图上按小车实际位置点选，按住左键向车头方向拖动，等待定位确认。
4. 选择“标记目标”，在空闲道路内点选；预览路径后点击“开始导航”。

文件已通过当前 App 的地图导入、导航上传格式校验和全部像素的占用值核对。**转换成功表示可以作为导航静态地图输入，不代表已完成实车定位和到达测试。**

AMCL 需要图上的黑块轮廓与雷达实际看到的实体轮廓相符。若黑块只是建筑用地区域、实际建筑轮廓不同，或外边框仅是无实体围挡的沙盘边缘，应结合真实雷达数据核对后调整地图；不能把绘制的边线直接当成已测得的墙体。右侧道路仅 25 厘米宽，规划是否允许通过还会受到车体、夹爪轮廓和安全间距影响，转换时没有缩小障碍物或放宽导航参数。

本次只在电脑生成地图文件，未连接小车，未改动小车内部文件或 App 代码，未产生实车录像。
