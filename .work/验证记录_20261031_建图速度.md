# 验证记录：建图速度改为页面内可调（2026-10-31）

## 背景
第一版把默认速度做成 `app/run.bat` 里的环境变量 `CARAPP_MAP_SPEED`。
用户反馈："我想要能在 app 的面板里直接控制，而不是使用代码。"
因此把控制权放回界面，`run.bat` 只保留"首次启动的初值"作用。

## 改动
1. `app/carapp/ui/teleoppanel.py`
   - 标签由「速度（m/s）」改为「建图速度（m/s）」，加粗显示。
   - 速度输入框右侧新增快捷按钮 `0.03 / 0.04 / 0.05 / 0.06 / 0.08`，单击即生效（`set_speed_value()`）。
   - `apply_speed()` 成功后把值格式化回输入框，并回调 `on_speed(value)`；回调异常只记日志，不影响驾驶。
   - `TeleopPanel.__init__(parent, ctx, ready=None, speed=None, on_speed=None)`。
   - 速度来源顺序：显式参数（页面配置）→ `CARAPP_MAP_SPEED` → 默认 0.04；越界夹紧 0.02–0.10。
2. `app/carapp/features/mapping.py`
   - 建图页用 `cfg.get("speed")` 初始化，并传入 `on_speed=self._speed_changed`。
   - 新增 `_speed_changed(value)`：写 `self.ctx.cfg["mapping"]["speed"]` 并 `save_config`，日志「建图速度已保存：x.xx m/s」。
   - 即：页面里改一次，`settings.json` 记住，重启后仍生效。
3. `app/run.bat`（GBK）
   - 保留 `if not defined CARAPP_MAP_SPEED set "CARAPP_MAP_SPEED=0.05"`，注释改为"界面还没保存过速度时用作初始值"。
4. `app/run.sh`：同步保留环境变量初值。
5. `README.md`：启动章节与沙盘建模章节改为"页面里直接改并自动保存；run.bat 只给初值"。

## 验证
- `tests.test_mapping_teleop` + `tests.test_mapping_feature`：36 tests OK。
  - 新增：快捷按钮设 0.06 后 `speed`/`controller.speed` 同步、`on_speed` 收到 0.06；
  - 新增：输入 0.50 被拒（不触发回调）；环境变量 0.07 时面板初值 0.07。
- run.bat 探针：不设 → 0.05；外部 0.03 → 保留；外部 0.9 → 由程序夹紧到 0.10。
- 分模块全量：`python .work\run_tests_per_module.py` → 见本次运行结果（`modules=50 ok=50 bad=0`）。

## 备注
- `settings.json` 里的 `mapping.speed` 在页面第一次改速后才会写入；删除该键即回到"初始值"逻辑。
- 运行中改速度会先停车（`apply_speed()` 里 `self.stop()`），再按新速度继续，属于原有行为。
