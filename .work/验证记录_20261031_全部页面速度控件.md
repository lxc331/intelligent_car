# 验证记录：全部移动页面统一速度控件（2026-10-31）

## 背景
用户（m03170）："你把这个功能添加到全部的小车移动功能附件"。
"这个功能" = 建图页刚做的速度控件：可输入、带快捷按钮、改完立即生效并自动保存。

## 改动
新增共用控件 `app/carapp/ui/speedpicker.py`：

```python
SpeedPicker(parent, label="速度（m/s）", low=.02, high=.15, value=.06,
            presets=(.03, .06, .10, .15), on_apply=None)
```

- 左侧标签 + 数字输入框（回车 / 失焦生效）+ 一排快捷按钮；
- 输入永远夹在 `[low, high]`，非法文本保留上一次有效值；
- `var` 是 `tk.StringVar`，页面可以把旧变量名指向它（`self.speed = picker.var`）以兼容既有代码与测试；
- 需要"改完即生效"的页面传 `on_apply`；需要"点应用/开始时才生效"的页面不传，自己在按钮里读值。

| 页面 | 控件 | 生效/保存 |
|---|---|---|
| 建图 | 建图速度（m/s），预设 0.03/0.04/0.05/0.06/0.08，范围 0.02–0.10 | 立即生效，写 `mapping.speed` |
| 遥控 | 速度（m/s），预设 0.06/0.10/0.15，范围 0.02–0.15 | 立即生效，写 `base.speed`；转向仍取 `base.turn_speed` |
| 夹取 | 速度（m/s），预设 0.06/0.10/0.15，范围 0.02–0.15 | 立即生效，写 `base.speed`（点动、持续移动、一键夹取共用） |
| 巡航 | 移动速度（米/秒），预设 0.03/0.06/0.10/0.15 | 点"应用设置"时校验并写 `cruise.speed`，下次启动巡航生效 |
| 导航 | 速度（m/s），预设 0.03/0.06/0.10/0.15 | 点"开始导航"时校验并写 `navigation.speed` |

兼容性：
- 遥控 / 夹取保留 `var_level` 属性（旧配置 `base.speed_levels` 仍作为预设值来源）；
- 夹取页 `_speed()` 优先用页面选定的精确速度，未选过时回退到 `base.speed_levels[level]`（测试里直接塞 `var_level` 的老用例仍成立）；
- 巡航 / 导航保留 `self.speed` 变量名，`apply_settings()`、`navigate()` 逻辑未改。
